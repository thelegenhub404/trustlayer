TrustLayer

Verify in 5 minutes that an agent is who it claims to be.

TrustLayer answers three questions: does this agent control the domain it claims? who has used it and how did it go? can I check it myself without trusting TrustLayer?

Trust levels

  • L0 — Unverified: listed from a seed; nothing checked.
  • L1 — Domain verified: valid did.json on the domain; id matches the host.
  • L2 — Identity verified: L1 + fingerprint anchored in DNS TXT + valid signature on trustlayer.json.
  • L3 — Reputation: L2 + at least 5 valid receipts from at least 3 different clients.

What TrustLayer does NOT guarantee

It guarantees that the agent controls the domain and that others have used it with a certain outcome. It does not guarantee that it treats your data well, that its output is free of prompt injection, or that it is correct. Treat every agent output as untrusted data.
