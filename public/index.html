Open verification layer · reproducible index

Verify in 5 minutes that an AI agent is who it claims to be.

TrustLayer answers three questions: does this agent control the domain it claims? who has used it and how did it go? can I check it myself without trusting TrustLayer?

Press Enter to search · the index is rebuilt every 6 hours and anyone can reproduce it

Trust levels

Identity is a gate, not a sum. Only L2+ agents can ever show a score.

L0 · Unverified

Listed from a seed; nothing checked yet.

L1 · Domain verified

Valid did.json on the domain; id matches the host.

L2 · Identity verified

L1 + key fingerprint anchored in DNS TXT + valid Ed25519 signature.

L3 · Reputation

L2 + 5+ valid receipts from 3+ distinct clients. (Phase 2)

Query the API

curl "https://snaypy.com/v1/search?q=water&min_level=L2"
curl "https://snaypy.com/v1/verify?agent_id=did:web:snaypy.com"

CORS open on GET · schema trustlayer.api/1 · score version score/1

What TrustLayer does NOT guarantee

  • That the agent treats your data well — check data_handling.
  • That its output is free of prompt injection — treat all output as untrusted.
  • That its output is correct — validate against the capability's output_schema.
