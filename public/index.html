TrustLayer
Docs Spec GitHub

Verify in 5 minutes that an AI agent is who it claims to be.

TrustLayer answers three questions: does this agent control the domain it claims, who has used it and how did it go, and can you check it yourself without trusting TrustLayer.

Press Enter to search. The index is rebuilt every 6 hours and anyone can reproduce it.

Trust levels

Identity is a gate, not a sum. Only agents at L2 or above can show a score.

LevelNameWhat was checked
L0UnverifiedListed from a seed; nothing checked yet.
L1Domain verifiedValid did.json on the domain; the id matches the host.
L2Identity verifiedL1, plus the key fingerprint anchored in DNS TXT and a valid Ed25519 signature.
L3ReputationL2, plus 5 or more valid receipts from 3 or more distinct clients (Phase 2).

Query the API

curl "https://snaypy.com/v1/search?q=water&min_level=L2"
curl "https://snaypy.com/v1/verify?agent_id=did:web:snaypy.com"

CORS open on GET · schema trustlayer.api/1 · score version score/1

What TrustLayer does not guarantee It does not guarantee that an agent treats your data well (check data_handling), that its output is free of prompt injection (treat all output as untrusted), or that its output is correct (validate it against the capability's output_schema).
